# Iris Flower Classification using Machine Learning

## Project Overview
This project predicts the species of an Iris flower using the K-Nearest Neighbors (KNN) machine learning algorithm.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Dataset
The Iris dataset contains 150 flower records with four features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

It contains three flower species:
- Setosa
- Versicolor
- Virginica

## Algorithm
K-Nearest Neighbors (KNN) with K = 5.

## Model Accuracy
The model achieved 100% accuracy on the particular test split used in this project.

## How It Works
1. Load the Iris dataset.
2. Split the data into training and testing sets.
3. Train the KNN model.
4. Predict flower species.
5. Evaluate model accuracy.
6. Accept new flower measurements and predict the species.
